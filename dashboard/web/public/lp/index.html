よくある質問

気になること

動画編集の経験がなくても使えますか？
使えます。やりたいことを普段の言葉で伝えれば、AI が手順を組み立てて実行します。編集ソフトの操作を覚える必要はありません。
本当に無料ですか？
AI Video Production OS とすべての部品は MIT ライセンスのオープンソースで、無料です。話しかける相手の AI（Claude Code や Codex など）の利用料は、それぞれのサービスの料金に従います。
動画がネットに勝手にアップロードされませんか？
されません。処理は基本的にあなたのパソコンの中で行います。YouTube への投稿のように外に送る機能は、あなたが頼んだときだけ動きます。どの部品が何をするかは、それぞれ公開された約束事（契約）に書かれています。
AI が作る動画ですか？
いいえ。文章から映像をまるごと作る生成 AI ではありません。あなたが撮った本物の動画を、カットや字幕、音量の調整で仕上げる道具です。
どんなパソコンで動きますか？
ターミナルで 1 行のコマンド（bash）を実行できるパソコンが必要です。部品によって必要なもの（ffmpeg など）があり、それぞれの説明書きで案内しています。
うまくいかなかったら、元の動画はどうなりますか？
元の動画はそのまま残し、仕上がりは別のファイルとして書き出します。何をしたかの記録も残るので、やり直しも簡単です。
まだできないことはありますか？
あります。AI の声でのナレーションや吹き替え、BGM と効果音の生成、YouTube 以外への投稿などは開発中です。いまの進み具合は進捗ダッシュボードでいつでも見られます。
Premiere Pro などの編集ソフトと一緒に使えますか？
編集の流れ（タイムライン）を OTIO という共通形式で書き出せます。Premiere Pro や DaVinci Resolve と直接やり取りする機能は、これから作る予定です。
