なぜ作ったか

ツールはつながらず、
AI は中身を見せない。

現場の映像制作は、編集、色、音、字幕、QC、納品がそれぞれ別のツールに分かれ、何が起きたかを共有する記録がありません。いま増えている AI ツールの多くは、プロンプトを入れて MP4 が出てくるだけの閉じた箱です。

これまで

  • 同じ計測を別々のツールが別々に実装し、誰も重複に気づけない
  • AI の出力が正しいかを確かめる手段がない
  • よいエンジンが出ても、周りを全部書き直さないと入れ替えられない

AI Video Production OS

  • 機械が読める契約で、各 Skill が何をできて何をするかを宣言
  • 各工程の結果を測り、判定と来歴を残してから次へ
  • Skill は独立したリポジトリ。契約を守れば、誰が作ったものでも差し替えられる

できること

現場の素材から、納品まで。

確かめてから、次へ進む

qc-skill の判定は 4 種類。測れなかったものは UNKNOWN のまま残し、黙って合格にはしません。

PASSWARNFAILUNKNOWN

部品ごとに差し替えられる

文字起こしも、音声処理も、字幕も、それぞれが独立したリポジトリ。skillpact の契約で副作用や依存を宣言するので、入れ替えても周りは壊れません。

収録素材をそのまま扱う

カードからの取込とチェックサム検証、文字起こし、話者分離、スライド切替の検出まで。学会やカンファレンスの収録を前提にしています。

音と字幕を、規格どおりに

ラウドネス正規化、フィラーと無音の除去、ダッキング。字幕は SRT と WebVTT の生成と検証、焼き込みに対応します。

ディスク納品まで自前で

Blu-ray（BDMV）と DVD-Video のオーサリング、UDF イメージ、Line 21 のクローズドキャプション。配信だけで終わらない案件にも対応します。

いつものエージェントから使える

Claude Code のプラグイン、Codex、MCP サーバーから呼び出せます。どの Skill を使い、どこで別の手段に切り替えたかも報告します。

しくみ

3 ステップで動きます。

01

まとめてインストール

1 行で OS、エージェント、ecosystem.json に載っているすべての Skill を取得します。もう一度実行すれば最新に更新されます。

curl -fsSL .../install.sh | bash
02

エージェントに頼む

Claude Code ならマーケットプレイスから追加。作りたいものを伝えると、エージェントが工程を計画し、必要な Skill を選びます。

/plugin marketplace add kajisho5/AI-video-production-OS /plugin install video-production-os@ai-video-production-os
03

測って、記録して、納品

各 Skill が実行し、QC が結果を判定します。入力のハッシュ、ツールの版、判定がすべて残るので、あとから同じ結果を再現できます。

qc PASS · WARN · FAIL · UNKNOWN → provenance.json

FAQ

よくある質問

AI で動画を生成するツールですか？
違います。プロンプトから MP4 を作る生成ツールではなく、実際の素材に対する編集、音声、字幕、QC、納品といった工程を、検証と記録つきで実行するための基盤です。
料金はかかりますか？
OS と各リポジトリは MIT ライセンスで無料です。任意で導入する AI エンジンや外部サービスは、それぞれのライセンスと料金に従います。
Premiere Pro や DaVinci Resolve の代わりになりますか？
なりませんし、目指していません。NLE とのタイムライン連携（nle-bridge-skill）は計画中で、まだ実装されていません。エージェントは OTIO でのタイムライン書き出しに対応しています。
素材がクラウドに送られることはありますか？
各 Skill はローカルでの実行が基本です。配信先へのアップロードや外部 AI プロバイダのように外部サービスを使う機能は、その副作用を skillpact の契約に宣言しています。どの機能がどこへ通信するかは、各リポジトリの契約と README で確認できます。
何が必要ですか？
インストーラーに必要なのは git です。ffmpeg や Python など、各 Skill が使うものはそれぞれの README に書いてあり、ffmpeg-skill doctor で環境を確認できます。
Claude 以外でも使えますか？
使えます。Codex 向けにはインストーラーが ~/.agents/skills にリンクを張ります。MCP サーバーも用意しています。Skill の多くは単体の CLI としても動きます。
開発中の Skill はどれですか？
上のエコシステム一覧で「開発中」と表示されているものです。AI による声の分離、ナレーションと吹き替え、BGM と効果音の生成、配信先へのアップロードがここに入ります。完成度は README とダッシュボードで正直に書いています。
自分で Skill を作って参加できますか？
できます。契約（skillpact）に沿って能力と副作用を宣言すれば、中心部分を作り直さずにエージェントから呼べます。手順は README の「Skill author experience」にあります。
